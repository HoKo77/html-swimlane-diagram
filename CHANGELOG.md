# Changelog

All notable changes to this project will be documented in this file.

## [v0.1.0] - 2026-05-27

### Added

- Initial `html-swimlane-diagram` Codex skill.
- Editable single-file HTML/SVG swimlane diagram output.
- Fixed-lane template with phase bands and sticky lane headers.
- Decision diamond conventions for `Y/N` approval and validation branches.
- Rework loop guidance for rejected approvals and exception handling.
- Reference guides for lane dimensions, process extraction, routing, and swimlane rules.
- Bundled Python connector linter for diagonal, crossing, and overlapping SVG links.
- Mall admin marketing campaign example input and generated HTML output.
- Repository validation script and GitHub Actions workflow.
- Chinese and English README files.
